## Why this combination achieves your goals

1. **"Smooth & robust, like Anthropic"** → `shadcn/ui + Tailwind + Framer Motion` is the closest practical path. Tailwind's design tokens enforce consistent spacing/layout, which is exactly what eliminates overlapping and gives the "solid" feel.

2. **"No overlapping"** → Radix UI (under shadcn) handles z-index, focus traps, and layering correctly out of the box for modals, dropdowns, tooltips.

3. **Performance (your dashboard concern)** → React Query caches data, so the Dashboard stays fast while the heavy Trends page lazy-loads its aggregation queries.

4. **Pairs cleanly with Spring Boot** → React talks to Spring Boot via REST + JWT. Standard, well-documented pattern.
